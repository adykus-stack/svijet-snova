# Svijet snova

Android aplikacija za stvaranje i slušanje dječjih priča na bosanskom i njemačkom jeziku. Priče i prirodni glas stvaraju se uz Gemini, a aplikacija dodaje instrumentalnu muziku prilagođenu raspoloženju priče.

## Instalacija na telefon

1. Otvori datoteku **Svijet-snova.apk** u ovom repozitoriju.
2. Pritisni dugme za preuzimanje.
3. Na telefonu otvori preuzetu datoteku i dozvoli instalaciju iz preglednika ako Android to zatraži.

Repozitorij i APK su privatni jer instalacijska datoteka sadrži Gemini API ključ. Nemoj dijeliti APK s drugim osobama.

## Pokretanje izvornog projekta

1. Otvori projekat u Android Studiju.
2. Napravi `.env` datoteku u glavnoj mapi projekta.
3. U nju dodaj `GEMINI_API_KEY=tvoj_kljuc` prema primjeru iz `.env.example`.
4. Poveži telefon i pokreni aplikaciju.

Datoteka `.env` nije uključena u GitHub repozitorij.
